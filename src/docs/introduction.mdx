# Herú

Headless web components built with [Lit](https://lit.dev). Behavior, accessibility and form participation are built in; the look is opt-in.

<heru-button type="button">Get started</heru-button>

## Install

```sh
pnpm add heru lit
```

```js
import 'heru/define'; // registers <heru-button>, <heru-text-field>
import 'heru/tokens.css'; // --heru-* design tokens (spacing, type, color, density)
import 'heru/theme.css'; // optional default look
```

Without `theme.css` the components are unstyled apart from structural sizing. Style them yourself with `::part()` and `:state()`.

## Principles

- **Headless first.** Components ship behavior and accessibility. Visuals live in tokens and an opt-in theme.
- **Many shallow components.** Small public elements, never one god component.
- **4px grid.** `--heru-unit` is the only primitive. `space-N` = N × 4px.
- **Density.** Set `data-heru-density="compact | default | comfortable"` on any element.
- **Minimal color.** One dark slate ramp and one error red, in OKLCH, behind semantic names like `--heru-color-text`.
- **Agent-readable.** Token names carry their values, and `heru/tokens.json` resolves every token to px / oklch / hex.

## Fonts

The theme uses Inter and JetBrains Mono through `--heru-font-family-sans` and `--heru-font-family-mono`. Font files are not bundled; load them in your app (this site loads them from Google Fonts).
