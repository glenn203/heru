# Prism

Headless web components built with [Lit](https://lit.dev). Behavior, accessibility and form participation are built in; the look is opt-in.

<prism-button type="button">Get started</prism-button>

## Install

```sh
pnpm add prism lit
```

```js
import 'prism/define'; // registers every tag: <prism-button>, <prism-text-input>, <prism-password-input>, …
import 'prism/tokens.css'; // --prism-* design tokens (spacing, type, color, density)
import 'prism/theme.css'; // optional default look
```

Without `theme.css` the components are unstyled apart from structural sizing. Style them yourself with `::part()` and `:state()`.

## Principles

- **Headless first.** Components ship behavior and accessibility. Visuals live in tokens and an opt-in theme.
- **Many shallow components.** Small public elements, never one god component.
- **4px grid.** `--prism-unit` is the only primitive. `space-N` = N × 4px.
- **Density.** Set `data-prism-density="compact | default | comfortable"` on any element.
- **Color made of light.** One airy slate neutral and a seven-hue refraction spectrum, in OKLCH with Display P3 and sRGB fallbacks, behind semantic names like `--prism-color-text`. Light and dark themes, both checked for AA contrast.
- **Agent-readable.** Token names carry their values, and `prism/tokens.json` resolves every token to px / oklch / hex.

## Fonts

The theme uses Inter and JetBrains Mono through `--prism-font-family-sans` and `--prism-font-family-mono`. Font files are not bundled; load them in your app (this site loads them from Google Fonts).
